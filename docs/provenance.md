# Provenance and safe-data policy

The remote RoboSynChallenge project is used read-only to identify delivery-artifact names and field conventions. The repository may commit only synthetic or manually anonymized minimal fixtures.

The field evidence that informed the current adapter is documented without source content in [reference-evidence.md](reference-evidence.md).

Never add remote paths, model weights, videos, raw datasets, 3D assets, cookies, tokens, private logs, or material with unclear redistribution rights. Read-only inventory encountered permission-denied historical snapshot policy directories; they are excluded from recursive metadata collection and are not needed by the current fixtures.

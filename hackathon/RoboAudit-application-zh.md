# RoboAudit.mbt 项目申报书

## 1. 项目名称

RoboAudit.mbt：结构化评测证据校验工具

## 2. 项目简介

不同 benchmark 的日志字段并不统一。RoboAudit.mbt 不依赖外部统一日志标准，而是在工具内定义公开的 canonical schema，将不同来源的 episode 评测结果归一化，再统一完成指标重算、协议校验、结果比较和报告生成。适用边界是“由多次 episode 构成、包含成功/失败结果的评测”，不试图处理任意业务日志。

## 3. 项目方向与通用性

项目方向为数据处理与开发者工具。核心模型 `Run`、`Episode`、`Stage`、`ArtifactRef`、`AuditFinding` 与来源格式分离；现有适配器支持 canonical JSON、JSONL、CSV 及 RoboSyn 风格输入。新增来源只需增加适配器，不需改动统计、校验和报告核心，可用于机器人、具身智能、仿真 benchmark 及其他 episode-based A/B 评测。

## 4. 预期使用场景

1. **Benchmark 维护者发布结果**：将不同执行器的 JSON、JSONL 或 CSV 归一化，重算成功率、Wilson 置信区间、动作步和失败类型，生成可复核报告。
2. **算法开发者比较版本**：导入升级前后的 episode 结果，先检查任务、协议和观测条件，再比较表现；协议不兼容时拒绝输出误导性差值。
3. **交付或复现审核者验收材料**：检查随机种子、重试、跳过记录、代码版本、来源和文件哈希，定位缺失证据并给出稳定规则编号。

## 5. 核心功能

- 公开 canonical schema 与四类输入适配器；
- 重算成功率、Wilson 95% 置信区间、动作步与失败分布；
- 使用 RA001-RA015 检查种子、重试、协议、交付物和来源；
- 进行协议安全的结果比较，生成指纹和 SHA-256 清单；
- 输出确定性 Markdown、JSON、CSV 报告，提供 100 项测试和双平台 CI。

## 6. 项目性质

本项目为原创项目，不是移植项目。解析、校验、统计、审计、比较和报告逻辑均使用 MoonBit 独立实现。

## 7. 参考与许可证

项目只读参考了 RoboSynChallenge 的常见字段和交付方式，没有复制其代码、模型、视频或原始数据。示例均为合成或匿名化数据，项目采用 Apache-2.0 许可证。因不是移植项目，不涉及移植来源许可证。
